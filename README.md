# 🛠️ TRI:DOTS – All Your Needs in One Place

**TRI:DOTS** is a modern mobile and web platform designed to simplify **equipment rentals** and **skilled labor hiring** for industries like construction, logistics, and events in Sri Lanka.

📱 Android App | 🌐 Web Portal | 🔐 Secure Login | 💬 In-App Chat | 💳 Stripe Payments

---

## 🚀 Features

- ✅ Dual Android apps: One for **Personal Users**, one for **Business Providers**
- 🔐 Firebase Authentication & Role-based access
- 🗓️ Real-time calendar booking system
- 💬 In-app messaging between users and service providers
- 💳 Secure payment gateway integration using Stripe (LKR)
- 📂 Ad listings and business profile management
- 🧑‍💻 Admin dashboard for moderation and management
